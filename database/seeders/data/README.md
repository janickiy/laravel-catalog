# Демонстрационные сайты

`DemoLinksSeeder` добавляет 134 опубликованные тестовые записи: по две в каждый
из 60 подразделов стандартного каталога, ещё десять в «Разработка ПО» для проверки
пагинации и четыре в «Разное». Для превью используются локальные SVG.

Запуск из каталога приложения:

```sh
php artisan db:seed --class=DemoLinksSeeder
```

Сидер запускается только в окружениях `local` и `testing` и намеренно не включён
в `DatabaseSeeder`. Повторный запуск пропускает существующие URL и сохраняет
внесённые изменения и просмотры. Адреса на `catalog-demo.example` вымышленные;
они предназначены для тестирования интерфейса. У тестовых записей поле `comment`
содержит метку `catalog-demo-v1`.
